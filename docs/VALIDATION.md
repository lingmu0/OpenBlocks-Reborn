## Redux 3：附魔

全源码 Java 21 编译通过；描述键、分页手册及资源引用检查通过。

新增六项无界面附魔 GameTest 在默认非宝藏和三个全部设为宝藏两种配置下通过：

1. 真实生存服务端玩家受到致命伤时先消耗图腾、不扣经验；无图腾时才由屹立不倒扣经验救活；默认无冷却可连续生效。
2. 经验不足、效果关闭、冷却中均不救、不扣经验；冷却到期重新允许救活。
3. 黄心先吸收伤害；半颗心以下但未死亡不触发；虚空可绕过原版图腾后由经验救活；实际 kill() 在经验足够时也可救活。
4. 实际加载的 treasure/non_treasure/in_enchanting_table 标签与配置一致，tradeable 和 on_random_loot 仍可获取。
5. 震荡不定关闭不消耗火药或取消摔落；默认 III 级爆炸不毁地形。尔虞我诈全关不累积厄运；单项开启才允许累积，总开关关闭仍能阻止效果。
6. 经验倍率和爆炸强度上下界正确；反胃和缓慢独立开关生效，禁用的一项不会随另一项施加。

测试使用正常 ServerPlayer 与内嵌连接，移除测试玩家出生保护；未启动客户端。图标、物品提示和配置界面的视觉效果仍需玩家实测。

Redux 3 另回归通过五项原有 Redux 测试和三项高亮仪测试，共十四项不同测试。最终 JAR 在 NeoForge 21.1.264 正式发行模式专用服务端成功启动并正常停止。高亮仪测试会清理前次合成场景中的村民，避免重复运行时旧记忆影响归属断言。
