# 电梯存档迁移范围

模组本身不自动改写既有存档。本文件说明 ID 和数据迁移范围；具体存档的备份、执行清单和验证记录应保存在源码仓库之外。

## 目标 ID

16 色目标方块与物品均为 `openblocks_reborn:elevator_<color>`。
普通与定向传送共用同一方块，通过 `directional`、`facing`、`show_arrow` 状态控制。

| 旧内容 | 迁移目标 |
|---|---|
| `elevatorid:elevator_<color>` 方块/物品 | `openblocks_reborn:elevator_<color>` |
| `elevatorid:elevator_tile` 方块实体 | `openblocks_reborn:elevator_tile` |
| 原重制版 `openblocks_reborn:elevator` | 按原 `color` 状态选择新 ID，普通模式 |
| 原重制版 `openblocks_reborn:elevator_rotating` | 按原 `color` 状态选择新 ID，启用定向并保留朝向 |

## 必须保留的内容

- 各维度区块中的方块坐标和状态，包括方向、定向开关及箭头显示。
- 方块实体的 `held_id` 伪装方块状态，包括朝向、半砖等属性。
- 玩家背包、末影箱、容器、掉落物、嵌套容器和物品组件中的电梯 ID。
- 数据组件内保存的方块实体/物品数据；不能只替换地上的方块。
- `elevatorid-server.toml` 中的全部电梯配置：同色要求、范围、激活范围、居中、刷怪、视角与经验消耗，迁入新电梯配置文件。

原重制版两种旧电梯不再注册，不能依靠普通合成配方转换已经无法加载的旧物品。

## 执行原则

确认具体存档并关闭游戏/服务器后，备份所有将修改的区域、数据、配置和模组文件，再在副本中转换。
先只读统计旧 ID 与 NBT 结构；发现与上述格式不一致的数据时暂停相关条目，保留原数据并报告。
转换后核对方块和物品数量、伪装状态与配置，启动副本检查缺失 ID，并实测普通/定向传送、染色和伪装。
副本验证完成后，才切换正式存档并移除独立 ElevatorMod。

实际执行必须另行记录源文件与目标文件校验值，保留回滚文件；不能把本说明当成迁移已经完成的证明。
