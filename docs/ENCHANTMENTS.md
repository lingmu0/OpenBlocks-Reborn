# 附魔设置与行为（Redux 3）

三种附魔都保留原有 ID、附魔书和装备数据。总开关默认开启；关闭仅停用效果，不删除现有附魔，也不自动移除获取途径。

| 附魔 | 效果默认值 | 可调参数 |
| --- | --- | --- |
| 屹立不倒 I–II | 开启；经验倍率 1；冷却 0 秒 | 总开关、倍率 0.1–10、冷却 0–600 秒 |
| 震荡不定 I–III | 开启；强度倍率 1；不破坏方块 | 总开关、倍率 0.25–2、III 级能否破坏方块 |
| 尔虞我诈 I–IV | 总开关开启，六项恶作剧全部关闭 | 总开关、交换快捷栏、弹射、反胃、缓慢、改名、传送六个独立开关 |

效果配置为服务器实例 `config/openblocks_reborn-enchantments-server.toml`。NeoForge 允许用存档 `serverconfig/` 下的同名文件覆盖。本次存档转换会在该存档里设置最终默认值，避免影响其他存档。客户端收到服务端效果设置，物品提示显示说明及停用状态。

屹立不倒在实际死亡事件中处理，原版不死图腾先判定成功就不扣经验、不开始冷却。图腾未救活时，检查总开关、冷却、护甲附魔和经验。各种伤害来源都允许，包括虚空与 /kill。经验不足不救，不扣部分费用。

成功时恢复 1 点生命。普通伤害保留旧版计费公式：ceil(50 × (1 − 减免和吸收处理后的预计生命) ÷ 护甲总等级 × 倍率)，最低 1 点经验。注意是经验点，不是经验等级。巨大伤害的费用上限为 2,147,483,647 点；允许 /kill 来源不等于普通经验储备一定付得起。直接调用死亡且无法取得伤害量时，按恢复 1 点生命的基础缺口计费。只有本附魔成功救活才开始冷却；暂停或离线时不计时。

震荡不定 I/II/III 级基础强度为 2/3/4，倍率后最终限制为 0.5–8；TNT 为 4。默认 III 级也不破坏方块。允许破坏时仅 III 级生效；I/II 级仍不破坏地形。方块保护不等于生物无伤，爆炸仍会影响附近实体。

尔虞我诈属于 PvP 恶作剧与反制，武器等级和防守方护甲总等级 / 3（向下取整）比较，弱方积累厄运。它不是佩戴者的持续负面诅咒，名称保留正常颜色，不加入原版 curses 标签。反胃和缓慢可独立开关；全部恶作剧关闭时不会积累厄运或播放恶作剧反馈。已有厄运数据暂存，重新启用效果后可继续处理。

获取配置为 `config/openblocks_reborn-enchantment-acquisition.toml`。三个 `treasure` 选项默认 false，依据旧版 1.12.2 JAR：三个类均未覆盖原版的宝藏判定。改为 true 后，进入 treasure 标签、退出 non_treasure，默认附魔台不再提供；交易和合适的随机战利品途径保留。修改后重启世界/服务器。自定义数据包仍可自行重写获取标签。

手册说明已分页，并修正屹立不倒最高等级为 II。增加常用 `.desc` 说明键，同时提供无需其他模组的物品提示；安装 Enchantment Descriptions 时避免重复插入说明。注册 NeoForge 自带配置界面，数值项具备上述范围校验。

按用户要求不启动客户端。图腾顺序、扣费、冷却、黄心、非致命伤、虚空、kill、配置标签和效果开关通过无界面服务端测试；提示布局与配置界面仍需玩家实测。
